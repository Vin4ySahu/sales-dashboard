This project is made using React based on the Figma design.

## Features

### UI Dashboard

- Created dashboard UI using React functional components
- Added header, charts, cards, tables, and sidebar sections
- Followed the provided Figma design layout

### API Integration

- Fetched users data using axios from:
  https://jsonplaceholder.typicode.com/users

### Data Table Features

- Search by name and email
- Sort names A-Z and Z-A
- Filter users by city
- Loading and error handling

### Optimization for better app performance

- Used Suspense
- Used lazy loading

### Tech Used

- React
- Tailwind CSS
- Axios
- Chart.js
- React router
- React-icons

---

## Project Setup Steps

### Create Vite React App

npm create vite@latest

cd sales-dashboard

npm install

npm install tailwindcss @tailwindcss/vite

npm run dev
